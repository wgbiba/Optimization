# Optimization Methods – Presentation Assignments

This repository contains a collection of presentation assignments related to **optimization methods and combinatorial optimization**.  
The materials cover the fundamental concepts of optimization modeling, integer programming, and exact algorithms used in operations research.

The assignments progress from basic optimization concepts to advanced exact algorithms used to solve complex combinatorial problems.

---

## Repository Contents

### 1. Optimization Introduction
**File:** `01_optimization_introduction.pdf`

This document introduces the basic concepts of optimization, including:

- What optimization is and why it is important
- Components of an optimization problem:
  - Decision variables
  - Objective function
  - Constraints
- Feasible and optimal solutions
- Mathematical formulation of optimization problems
- Continuous vs discrete optimization
- Examples of combinatorial optimization problems

---

### 2. Linear, Integer, and Mixed-Integer Programming
**File:** `02_linear_integer_mixed_programming.pdf`

This assignment focuses on optimization modeling techniques such as:

- Linear Programming (LP)
- Integer Programming (IP)
- Mixed-Integer Linear Programming (MILP)
- Binary decision variables
- Logical constraints modeling
- Big-M formulation
- Linearization of min/max and piecewise functions
- Practical modeling exercises

---

### 3. Primal–Dual Bounds and Branch-and-Bound
**File:** `03_primal_dual_bounds_branch_and_bound.pdf`

Topics covered in this assignment include:

- Primal and dual bounds
- Optimality gap
- LP relaxation of integer programs
- Duality in linear programming
- Bounding techniques
- Lagrangian relaxation
- Branch-and-Bound algorithm
- Flowcharts and pseudocode for exact algorithms

---

### 4. Exact Algorithms for Combinatorial Optimization
**File:** `04_exact_algorithms_combinatorial_optimization.pdf`

This assignment explores advanced exact algorithms such as:

- Complete enumeration (brute-force)
- Dynamic Programming
- Branch-and-Bound
- Constraint Programming
- Decomposition methods
  - Benders decomposition
  - Dantzig–Wolfe decomposition
- Cutting planes and Branch-and-Cut
- Column generation and Branch-and-Price
- Algorithm design with flowcharts and pseudocode
